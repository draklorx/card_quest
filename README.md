# Card Quest

A starter Vue 3 application built with Vite and TypeScript.

## Get started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the dev server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Lint the project:
   ```bash
   npm run lint
   ```

## Project structure

- `src/` — Vue components and app entry point
- `index.html` — application shell
- `vite.config.ts` — Vite configuration
- `.eslintrc.cjs` — lint rules for Vue and TypeScript
